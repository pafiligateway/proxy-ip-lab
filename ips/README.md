## Files

- `general/best.txt` — best-for-all across every operator and country, top N (one `ip:port` per line)
- `general/<COUNTRY>.txt` — best-for-all IPs for one country (panel reads these)
- `general/results.json` — full metrics with per-operator scores
- `general/best.csv` — spreadsheet-friendly top-N snapshot
- `operators/<operator>/best.txt` — all IPs for that operator
- `operators/<operator>/<country>.txt` — that operator's IPs in one country
- `countries/<country>/best.txt` — every operator's IPs for one country
- `providers/<provider>/best.txt` — ranked list per hosting provider
- `global/best.txt` — global top 100
- `index.json` — machine-readable index

> Packet loss is measured as failed TCP/TLS probes. Throughput uses Cloudflare's speed endpoints through each IP. 
> Only test IPs you are allowed to use. Scores reflect the network the test was run from.
